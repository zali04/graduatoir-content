# GraduaToIr content

Monthly social media content for GraduaToIr (FB Page, FB Group, Instagram), generated with the `graduatoir-content` skill in `.claude/skills/`.

- `content/YYYY-MM/{page,group,instagram}.js`: the posts (dates, slide text, captions)
- `content/YYYY-MM/out/<channel>/`: rendered images, reels and `caption.txt` per post
- `content/HISTORY.md`: topics already used
